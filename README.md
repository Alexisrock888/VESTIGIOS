# Vestigios

Sitio web de Vestigios, desarrollado con React y Vite.

## Requisitos

- Node.js y npm

## Desarrollo

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
npm run preview
```

Las imágenes del proyecto están en `images/`. Las dependencias instaladas, la compilación (`dist/`), los archivos de entorno y los documentos PDF no se incluyen en el repositorio.
